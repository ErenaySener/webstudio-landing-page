# WebStudio Landing Page

A responsive landing page built with HTML, CSS and JavaScript.

The project includes a modern multi-section layout, responsive navigation, interactive modal functionality, portfolio cards and adaptive design for desktop, tablet and mobile devices.

## Live Demo

[View the live website](https://erenaysener.github.io/webstudio-landing-page/)

## Features

- Responsive layout for desktop, tablet and mobile
- Mobile navigation menu
- Interactive service request modal
- Hero section with call-to-action
- Features section
- Team section
- Portfolio gallery with hover effects
- Responsive and retina-ready images
- SVG icons
- Contact and subscription form layouts
- Keyboard support for closing menus and modal with `Escape`

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Design
- Flexbox
- Media Queries
- SVG
- GitHub Pages
